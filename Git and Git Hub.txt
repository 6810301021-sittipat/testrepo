สรุป: เริ่มต้นใช้งาน Git และ GitHubสถานะ: แปลอัตโนมัติจาก อังกฤษ

ในโมดูลนี้คุณได้เรียนรู้ว่า:

- Git เป็นระบบควบคุมเวอร์ชันอเนกประสงค์ที่ใช้สำหรับการติดตามการเปลี่ยนแปลงในโค้ดและทำงานร่วมกับผู้อื่นในโครงการซอฟต์แวร์

- เนื่องจากระบบควบคุมเวอร์ชันแบบกระจาย Git ช่วยให้คุณกลับสู่สถานะก่อนหน้าหรือตรวจสอบประวัติของโครงการ

- GitHub เป็นหนึ่งในบริการเว็บโฮสต์ยอดนิยมสำหรับที่เก็บ Git

- ที่เก็บเป็นโครงสร้างที่เก็บข้อมูลที่จัดเก็บเอกสาร รวมถึงซอร์สโค้ดของแอปพลิเคชัน และช่วยให้ผู้มีส่วนร่วมสามารถติดตามและรักษาการควบคุมเวอร์ชันได้

- แบบจำลองที่เก็บ Git
 - มุ่งเน้นไปที่การติดตามซอร์สโค้ดในระหว่างการพัฒนา

 - ประกอบด้วยองค์ประกอบเพื่อประสานระหว่างโปรแกรมเมอร์ ติดตามการเปลี่ยนแปลง และสนับสนุนเวิร์กโฟลว์ที่ไม่ใช่เชิงเส้น

- ที่เก็บเป็นโครงสร้างการจัดเก็บที่เก็บรหัสและติดตามประวัติเวอร์ชันโดยใช้ Git แพลตฟอร์มเช่น GitHub ขยายพื้นที่เก็บเหล่านี้ด้วยคุณสมบัติเพิ่มเติมเช่นการติดตามปัญหาและเครื่องมือการทำงานร่วมกัน

- GitHub ช่วยให้คุณสามารถสร้างที่เก็บ แก้ไขไฟล์โดยใช้เว็บอินเตอร์เฟส ดำเนินการเปลี่ยนแปลงไฟล์อัปโหลดไฟล์ และอื่น ๆ อีกมากมาย
